# 영어 교실 게임

설치 없이 브라우저에서 바로 여는 단일 HTML 게임 모음입니다.

| 파일 | 게임 | 설명 |
|---|---|---|
| `bomb-pass.html` | 째깍째깍 폭탄 돌리기 | 주제에 맞는 단어를 외치며 폭탄을 넘기는 게임 |
| `word-chain.html` | 영어 끝말잇기 | 온라인 사전으로 단어를 확인하는 끝말잇기 |
| `sentence-arrange.html` | 영어 문장 배열 | 기본 문장 480개(1~4단계) 내장, 단계 선택, 팀전 지원. 문장은 직접 추가도 가능 |

- 인터넷 연결: 글꼴(Pretendard)과 끝말잇기의 온라인 사전 조회에만 필요합니다. 연결이 없어도 기본 글꼴로 동작합니다.
- 문장 배열의 문장 모음집은 사용하는 기기의 브라우저(localStorage)에 저장됩니다.
